Grammar · Habitual behaviour

Where does the frequency adverb go?

Frequency adverbs (always, usually, often, sometimes, rarely, never...) go before the main verb and after an auxiliary verb or be. Some can also start a sentence; others can't.

Correct or incorrect?

Is the adverb in the right position in each sentence?

Grammar · Past habits

Used to or would?

Both describe past habits that don't happen any more, but only one of them works with states (verbs like be, have, like, know).

Rule: would only works with repeated actions. For states (be, have, like, want, know...), use used to.

Repeated action, state or one-off event?

Read the text. For each underlined verb, decide: (a) both used to and would are possible, (b) only used to is possible, or (c) neither is possible, because it's a single event and not a habit.

Grammar · Used to

Be used to, get used to and used to

be used to = already accustomed to something (a state).
get used to = becoming accustomed to something (a process, a change).
used to + infinitive = a past habit that has stopped.

After be/get used to, always use an -ing form or a noun, never an infinitive.

Complete with the correct form

Use used to, be used to or get used to in the right form.

-ing or -ed adjectives?

-ed adjectives describe how we feel: I'm tired after the journey.
-ing adjectives describe the thing or person that causes the feeling: The journey was very tiring.
